Descargar .xpi

Instalar (una sola vez)

  1. Descargá el archivo .xpi con el botón de arriba.
  2. Abrí Floorp y escribí about:addons en la barra de direcciones.
  3. Clic en el engranaje (⚙) → Instalar complemento desde archivo…
  4. Elegí el .xpi descargado y confirmá.
  5. Abrí una pestaña nueva (Ctrl+T): FLOORP SYSTEM arranca.

Actualizaciones automáticas

Una vez instalada una versión que incluya el canal de actualizaciones, Floorp consulta este endpoint y ofrece las versiones nuevas solo:

updates.json

Nada de descargas manuales: el navegador compara la versión instalada con la publicada y actualiza cuando hay una mayor.

Importante

Las versiones instaladas antes de que existiera el canal de actualizaciones no tienen la dirección de este endpoint guardada, así que no pueden actualizarse solas. Hay que instalar una vez la versión actual; a partir de ahí, todas las siguientes llegan automáticamente.

Comprobar que funciona

about:support  →  sección "Extensiones"  →  buscar FLOORP SYSTEM y su versión

Si la versión mostrada sube después de una publicación nueva, las actualizaciones automáticas están funcionando.
